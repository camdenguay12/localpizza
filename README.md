# Local Pizza — reusable restaurant website template

A mobile-first, New England neighborhood pizza and sub shop demo using scarlet red, dark green and cream, with a sample pizza-slice SVG logo and sample phone number.

## Customize for a client
1. Edit `restaurant.json` to update restaurant name, address, phone, hours, story, menu categories, items and prices.
2. Update the hero and feature photo URLs in `style.css` with images you have permission to use.
3. Adjust colors in `:root` in `style.css`.
4. Add a real ordering URL to `orderUrl` in `restaurant.json`. Without one, the order button links to the menu.
5. Replace demo menu items/prices and placeholder contact information before presenting as a real business website.

## Deployment
Static HTML/CSS/JS; no build process. Compatible with a static host. If using GitHub Pages for demos, review its commercial-use restrictions before deploying client sites commercially. Custom domain and host should belong to the client.

## Files
- `index.html`: homepage, menu, story and contact sections
- `style.css`: design and mobile layout
- `script.js`: loads restaurant config, builds menu and navigation
- `restaurant.json`: all restaurant-specific content

**Demo only:** New England Pizza is a fictional placeholder brand. Menu prices and hours are illustrative, not factual. Photos are externally hosted examples and should be replaced with licensed client imagery before selling.
